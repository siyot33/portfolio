Mi entorno de trabajo

Cómo funciona la web y qué herramientas utilizo para crear mi portfolio.

¿Qué ocurre cuando escribo una URL?

Cuando escribo una dirección web en el navegador y pulso Intro, comienza un proceso para encontrar el servidor donde está alojada la página y solicitar sus archivos.

  1. El navegador interpreta la URL y localiza el dominio. Para encontrar su dirección IP consulta el sistema DNS.
  2. Con la dirección IP, el navegador establece una conexión con el servidor. En una web segura se utiliza HTTPS.
  3. El navegador envía una petición HTTP al servidor para pedir el recurso, normalmente una página.
  4. El servidor recibe la petición y devuelve una respuesta HTTP con el contenido solicitado, por ejemplo HTML, CSS, JavaScript e imágenes.
  5. El navegador interpreta esos archivos, construye la página y muestra el resultado en la pantalla.

Este intercambio es un ejemplo del modelo cliente-servidor: el navegador actúa como cliente porque solicita información, y el servidor responde enviando los recursos de la página.

Herramientas que utilizo

  • Visual Studio Code (VS Code): es el editor que utilizo para escribir y organizar el código HTML, CSS y otros archivos del proyecto.
  • Extensiones: añaden funciones al editor. Por ejemplo, un corrector ortográfico ayuda a revisar los textos y las herramientas de formato ayudan a mantener el código ordenado.
  • Live Server: permite abrir la página en el navegador mediante un servidor local y actualizarla al guardar los cambios.
  • Git: es el sistema de control de versiones. Sirve para guardar puntos del historial del proyecto, consultar cambios y volver a una versión anterior.
  • GitHub: es una plataforma donde puedo alojar el repositorio Git, compartir el código y publicarlo para que otras personas puedan verlo.

Estructura de carpetas del portfolio

He organizado los archivos del proyecto de esta manera:

portfolio/
├── index.html
├── entorno.html
├── README.md
└── img/
    └── .gitkeep

Los dos archivos HTML contienen las páginas del portfolio. El archivo README.md explica de qué trata el proyecto y qué tecnologías utiliza. La carpeta img está reservada para las imágenes que pueda añadir más adelante. El archivo .gitkeep permite que Git conserve la carpeta aunque todavía esté vacía.
